سياسة الاستخدام المقبول

معايير الاستخدام المسؤول والآمن لمنتجات وأنظمة وخدمات ومجتمعات أرشون تك.

رمز الوثيقة: AT-POL-003الإصدار: 1.0الحالة: وثيقة مؤسسية عامةآخر تحديث: 22 نوفمبر 2026

محتويات الوثيقة

نطاق السياسةالاستخدام المشروع والمسؤولالأفعال المحظورةالأمن السيبراني والاختبارات التقنيةالذكاء الاصطناعي والمحتوى الآليالإبلاغ عن الانتهاكاتالتعامل مع المخالفاتالتصاريح والاستثناءات والتحديثات

تهدف هذه السياسة إلى حماية المستخدمين والأنظمة والمجتمعات والأطراف الأخرى، وتحدد السلوك المقبول عند الوصول إلى أي خدمة رقمية تديرها أرشون تك.

1. نطاق السياسة

تسري على المواقع والتطبيقات والبرمجيات والأنظمة والمنتجات والخدمات وقنوات المجتمع والدعم التي تديرها أرشون تك، وعلى كل من يستخدمها أو يصل إليها.

2. الاستخدام المشروع والمسؤول

يجب استخدام الخدمات للأغراض المشروعة ووفق الصلاحيات الممنوحة، واحترام خصوصية الآخرين وحقوق الملكية الفكرية، وتقديم معلومات صحيحة، والمحافظة على أمن الحسابات والأجهزة.

3. الأفعال المحظورة

يحظر الوصول غير المصرح به أو محاولة تجاوز وسائل الحماية أو تعطيل الخدمات أو إجراء مسح أمني غير مصرح به أو استغلال ثغرة أو استخراج بيانات دون إذن.

يحظر إنشاء أو نشر أو إرسال البرمجيات الضارة أو التصيد أو الاحتيال أو انتحال الهوية أو إرسال الرسائل المزعجة أو التهديد أو التحرش أو نشر محتوى غير قانوني أو منتهك للحقوق.

يحظر استخدام الخدمات لتخزين أو نشر بيانات شخصية للغير دون أساس مشروع، أو إعادة بيع الوصول أو التحايل على حدود الاستخدام أو إساءة استخدام الموارد.

4. الأمن السيبراني والاختبارات التقنية

لا يجوز إجراء اختبارات اختراق أو فحص ثغرات أو محاولات وصول إلى نظام أو شبكة تخص أرشون تك أو طرفًا آخر إلا بعد الحصول على تصريح مكتوب يحدد الأنظمة والنطاق والتوقيت والأساليب المسموحة.

يجب الالتزام بنطاق التصريح وعدم الوصول إلى بيانات حقيقية أو استخراجها أو تغييرها أو تعطيل الأنظمة. وتُبلغ الثغرات بصورة مسؤولة عبر قناة الدعم الرسمية.

5. الذكاء الاصطناعي والمحتوى الآلي

يجب عدم استخدام أدوات الذكاء الاصطناعي أو الأتمتة لإنتاج احتيال أو تضليل أو محتوى ضار أو انتهاك خصوصية أو التحايل على ضوابط الخدمات. ويظل المستخدم مسؤولًا عن مراجعة المخرجات والتحقق منها قبل الاعتماد عليها.

6. الإبلاغ عن الانتهاكات

يمكن الإبلاغ عن إساءة الاستخدام أو مشكلة أمنية عبر مركز الدعم الرسمي، مع تقديم معلومات كافية لتحديد الواقعة دون جمع أو إرسال بيانات غير ضرورية.

7. التعامل مع المخالفات

قد تشمل الإجراءات التنبيه أو إزالة المحتوى أو تقييد وظيفة أو تعليق الحساب أو إنهاء الوصول أو الإحالة للجهات المختصة، بحسب جسامة المخالفة والقانون والاتفاقات السارية. ولا تمنع هذه الإجراءات أي حقوق قانونية أخرى.

8. التصاريح والاستثناءات والتحديثات

أي استثناء يتطلب موافقة مكتوبة من الجهة المخولة وتحديد نطاقه. وقد تُحدث السياسة عند تطور الخدمات أو المخاطر، ويُنشر تاريخ آخر تحديث. للاستفسارات استخدم مركز الدعم الفني.

هذه وثيقة مؤسسية عامة. إذا كان أحد منتجات أو خدمات أرشون تك يتطلب طريقة معالجة أو شروطًا مختلفة، فيجب الرجوع إلى الإشعار أو الاتفاق التكميلي الخاص بذلك المنتج، مع عدم الانتقاص من الحقوق التي يقررها القانون.
